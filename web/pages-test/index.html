Vocalgraph browser tests

Checks, from this GitHub Pages address, the three things Vocalgraph's browser version needs. Nothing you record or measure leaves this computer: the test audio is built in, and results only go to the helper on this computer.

1. The local helper

Start it first: in the Vocalgraph folder, uv run python web/helper-prototype/helper.py. Play something in a program (music, a video) so there is sound to receive. Your browser may ask to let this site reach devices on your computer or local network: allow it, that is what's being tested.
